This repository contains the code accompanying the Scientific Data manuscript **"Mapping rural livelihood strategies in China using deep learning"**. It implements the Deep Rural Livelihood Model (DRLM), a deep-learning framework that combines satellite imagery, household-survey-derived livelihood labels, sample expansion, and region-adaptive mapping to produce spatially explicit rural livelihood probability maps for China in 2020.

The associated data products are available from Zenodo: [https://doi.org/10.5281/zenodo.18489933](https://doi.org/10.5281/zenodo.18489933).

## Overview

Rural livelihood strategies shape land use, sustainability outcomes, ecosystem services, and rural transformation. However, nationally consistent, spatially explicit data describing livelihood composition remain scarce because household surveys are costly, infrequent, and usually unavailable at fine spatial resolution.

This project addresses that gap by mapping four rural livelihood strategy probabilities across rural China:

- farming-only (`F`)
- farming-dominated mixed non-farming (`F_NF`)
- non-farming-dominated mixed farming (`NF_F`)
- non-farming-only (`NF`)

The workflow uses household survey information from rural observation sites, expands sparse survey-derived labels to rural settlement polygons with quantile-regression XGBoost, and trains a dual-branch ResNet model to infer livelihood composition from Landsat and VIIRS imagery. The final product is a set of 90 m rural livelihood probability maps for 2020.

## Data Product

The dataset generated by this study has been deposited in Zenodo:

[**Mapping rural livelihood strategies in China using deep learning**](https://doi.org/10.5281/zenodo.18489933)

The primary data products are five GeoTIFF raster layers at 90 m spatial resolution:

| File | Description |
| --- | --- |
| `F_2020_90m.tif` | Probability of farming-only livelihood strategy |
| `F_NF_2020_90m.tif` | Probability of farming-dominated mixed non-farming livelihood strategy |
| `NF_F_2020_90m.tif` | Probability of non-farming-dominated mixed farming livelihood strategy |
| `NF_2020_90m.tif` | Probability of non-farming-only livelihood strategy |
| `max_confidence_2020_90m.tif` | Maximum probability among the four livelihood components |

For the four livelihood probability layers, pixel values range from 0 to 1 and sum to unity at each valid pixel. The maximum-confidence layer indicates the dominance of the largest predicted component, with values closer to 1 suggesting stronger dominance and values closer to 0.25 indicating more ambiguous or mixed livelihood composition.

The Zenodo release also includes supporting files for model training and validation, including:

- `RS_sampleData.shp`, the expanded rural settlement sample layer with model-assisted livelihood composition labels
- `Expansion_of_samples_2020_withXGBoost.csv`, containing median, 5th percentile, and 95th percentile estimates from the sample expansion step
- provincial boundary data used for macro-region assignment
- supporting CSV files documenting model diagnostics, regional validation, SHAP summaries, baseline comparisons, and independent survey-based validation

Raw household survey records, CFPS records, raw satellite imagery, and third-party source datasets are not redistributed.

## Livelihood Strategy Definitions

The model predicts a four-part compositional vector representing the probability of each livelihood strategy. These categories are defined from household income composition and follow the manuscript's four-category framework.

| Component | Abbreviation | Description |
| --- | --- | --- |
| Farming-only | `F` | Livelihoods rely entirely or predominantly on agricultural production. |
| Farming-dominated mixed non-farming | `F_NF` | Farming remains the dominant income source, with supplementary off-farm or non-farming income. |
| Non-farming-dominated mixed farming | `NF_F` | Non-farming income dominates, while farming remains a secondary activity. |
| Non-farming-only | `NF` | Livelihoods rely entirely or predominantly on non-agricultural employment or business activities. |

The four probabilities satisfy the compositional constraint:

```text
F + F_NF + NF_F + NF = 1.0
```

## Framework

The workflow integrates survey data, geospatial analysis, satellite imagery, and deep learning:

1. Construct livelihood composition labels from China's National Rural Fixed Observation Survey.
2. Geocode rural observation sites and aggregate livelihood composition within local buffer zones.
3. Use rural settlement polygons as the basic spatial units for sample expansion and mapping.
4. Apply quantile-regression XGBoost to expand sparse survey-derived labels to 38,306 rural settlement polygons.
5. Export and standardize Landsat and VIIRS imagery in Google Earth Engine.
6. Train DRLM using the expanded settlement-level label layer.
7. Train both a global model and macro-region models to balance national consistency and regional heterogeneity.
8. Generate national-scale livelihood probability maps using fixed region-adaptive ensemble weights.

The expanded settlement-level layer should be understood as a model-assisted label layer rather than direct household observations. This distinction is important for interpreting the released maps and validation results.

## Model Architecture

### DualResNet-Dirichlet

Our **DualResNet-Dirichlet** model uses a dual-branch architecture for multi-modal satellite inputs.

<img width="1042" height="528" alt="image" src="https://github.com/user-attachments/assets/67ac3050-e451-4bb6-8846-f7c97bd78c49" />

The daytime branch processes seven Landsat bands, while the nighttime branch processes VIIRS-DNB nighttime lights. The extracted features are fused and passed through residual blocks. A Dirichlet regression head outputs positive concentration parameters, which are normalized to produce compositional probabilities for the four livelihood strategies.

| Model element | Description |
| --- | --- |
| Daytime input | Landsat red, green, blue, NIR, SWIR1, SWIR2, and thermal bands |
| Nighttime input | VIIRS-DNB nighttime light band |
| Patch size | `64 x 64` pixels |
| Output shape | `[B, 4, 64, 64]` |
| Loss function | Dirichlet negative log-likelihood |
| Optimization | AdamW, gradient clipping, learning-rate scheduling, and early stopping |

### Region-Adaptive Ensemble

The final mapping step combines the global model and macro-region models using fixed regional weights. These weights were defined as a transparent diagnostic rule based on regional model behavior, sample availability, and holdout performance patterns.

| Macro-region | Global model weight | Region-informed model weight |
| --- | ---: | ---: |
| Northwest | 0.40 | 0.60 |
| East | 0.50 | 0.50 |
| Central South | 0.65 | 0.35 |
| Northeast | 0.80 | 0.20 |
| Southwest | 0.80 | 0.20 |
| North | 1.00 | 0.00 |

## Technical Validation

The manuscript evaluates the dataset using a tiered validation framework. This is essential because the final maps are probabilistic spatial proxies, not direct measurements of household livelihood choices.

### Internal Reconstruction

The global deep learning model trained with the expanded settlement-level label dataset showed strong agreement with the XGBoost-expanded labels for 29,410 rural settlements:

| Component | R2 against expanded labels |
| --- | ---: |
| `F` | 0.893 |
| `F_NF` | 0.868 |
| `NF_F` | 0.835 |
| `NF` | 0.823 |

These values describe agreement with the model-assisted expanded label layer and should not be interpreted as independent external validation.

### Region-Informed Validation

Macro-region modelling showed spatially heterogeneous performance. Some regions benefited from region-informed models, whereas regions with sparse samples or complex internal heterogeneity relied more heavily on the global model. This result motivated the fixed region-adaptive weighting strategy used in national inference.

### Independent Survey-Based Validation

Independent validation against 241 fixed rural observation sites from 2016 provided more conservative support for the dataset. The farming-only component showed the strongest agreement (`R2 = 0.75`, `RMSE = 0.16`). Mixed livelihood categories showed moderate but consistent agreement, reflecting the greater heterogeneity of transitional livelihood structures.

County-level comparison with China Family Panel Studies income-share indicators provided a directional check rather than point-level validation. Dominant livelihood categories showed statistically significant positive associations with agricultural and non-agricultural income-share indicators.

## Data Preparation

The data preparation stage follows the manuscript workflow and includes four main steps.

### 1. Export Satellite Imagery From Google Earth Engine

Run `Export_images_from_GEE.js` in the Google Earth Engine Code Editor. Then use `特征影像z_score处理.ipynb` to standardize each band using z-score normalization.

Expected output:

```text
exported_images/
|-- Landsat_RED_2020_90m_zscore.tif
|-- Landsat_GREEN_2020_90m_zscore.tif
|-- Landsat_BLUE_2020_90m_zscore.tif
|-- Landsat_NIR_2020_90m_zscore.tif
|-- Landsat_SWIR1_2020_90m_zscore.tif
|-- Landsat_SWIR2_2020_90m_zscore.tif
|-- Landsat_TEMP1_2020_90m_zscore.tif
`-- VIIRS_2020_90m_zscore.tif
```

### 2. Process Township And Settlement Data

Use the township and settlement preprocessing notebooks:

- `全国乡镇代码匹配到乡镇调查和街景数据.ipynb`
- `全国乡镇街道办事处牧场等重分类为0或1.ipynb`

These scripts align township codes, classify settlement units, and prepare spatial predictors used for sample expansion.

### 3. Expand Sparse Survey Labels

Run:

- `样本扩充_分位数XGBoost回归.ipynb`

This notebook applies quantile-regression XGBoost to expand sparse survey-derived livelihood compositions to the national rural settlement layer. It produces median estimates and uncertainty intervals for each livelihood component.

### 4. Prepare Final Training Samples

The final sample layer should include the following attributes:

```text
ID        Unique settlement identifier
F         Farming-only probability
F_NF      Farming-dominated mixed non-farming probability
NF_F      Non-farming-dominated mixed farming probability
NF        Non-farming-only probability
longitude X coordinate
latitude  Y coordinate
```

The four livelihood components should sum to one for each valid sample.

## Model Training

### Stage 1: Global Random Cross-Validation

Script:

```bash
python Model/00.Train_complete_Random-5-Fold-CV.py
```

This script trains the global DRLM model using five-fold random cross-validation. It is used to evaluate national-scale reconstruction of the expanded settlement-level label layer.

Outputs include:

- fold-specific trained model files
- `stage2_fraction_results.csv`
- diagnostic plots generated with `Model/01.Plot_results.ipynb`

### Stage 2: Region-Informed Macro-Region Models

Script:

```bash
python Model/00.Train_Out-of-Region_5-fold-CV.py
```

This script trains six macro-region models to characterize regional heterogeneity. The region-informed design reserves part of each target region for testing while retaining limited local information during training, approximating realistic mapping conditions where some local labels are available.

## Inference and Mapping

Script:

```bash
python Model/02.inference_2020_random_add_region_全像元.py
```

The inference script applies the global and region-informed models to national-scale satellite image stacks and combines them using fixed macro-region weights.

Expected output products:

```text
maps_2020_ensemble_regional_adaptive/
|-- pred_ensemble_adaptive_F_2020_90m.tif
|-- pred_ensemble_adaptive_F_NF_2020_90m.tif
|-- pred_ensemble_adaptive_NF_F_2020_90m.tif
`-- pred_ensemble_adaptive_NF_2020_90m.tif
```

Each pixel contains probability values from 0 to 1. The four component layers should sum to one at each valid pixel.

## Usage Notes

The four probability layers should be interpreted as compositional estimates of rural livelihood structure, not as hard classifications of individual households or villages. The full probability vector is more informative than a single dominant class, especially in regions where mixed livelihood strategies are common.

Recommended uses include:

- settlement-, county-, prefecture-, and regional-scale analysis
- comparison of rural livelihood structures across regions
- integration with environmental, land-use, food-security, ecosystem-service, and rural-development indicators
- exploratory analysis of rural transformation and socio-ecological change
- sampling design for future field surveys

The maps should not be used as substitutes for contemporary household surveys when household-level inference, individual-village targeting, or program eligibility decisions are required. Independent validation provides stronger support for dominant livelihood categories than for mixed transitional categories; users interested in mixed strategies should interpret the probability layers together with the maximum-confidence layer.

## Troubleshooting

### Out Of Memory

Reduce batch size in the training or inference scripts:

```python
BATCH_SIZE = 128
```

### Windows Multiprocessing Issues

Set:

```python
NUM_WORKERS = 0
```

### Path Configuration

Update data paths in the scripts to match your local file structure:

```python
DAY_TIFS = [
    r"YOUR_PATH\Landsat_RED_2020_90m_zscore.tif",
    # ... seven Landsat bands
]
NIGHT_TIF = r"YOUR_PATH\VIIRS_2020_90m_zscore.tif"
LABEL_SHP = r"YOUR_PATH\Sample_2020.shp"
PROVINCE_SHP = r"YOUR_PATH\Provinces_China.shp"
```
